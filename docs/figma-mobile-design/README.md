# Figma mobile design

Exports of the phone design from Figma, as the designer sent them. Each screen is 402×874. All text is outlined as vector paths, so the font names aren't in the files.

The SVG exports leave out the images. Six screens also come as PDFs that include them: the map behind Main Screen and Main Screen Click, and the map that fades into the background plus the ICEPik logo above the card on Log In, Sign Up, Forgot Password and Code Verification. Where there is a PDF, it shows the full design. (`Login-ICEPik.pdf` was exported as `Login-ICEPk.pdf`; it is renamed to match its SVG.)
